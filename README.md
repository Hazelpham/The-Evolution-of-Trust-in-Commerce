## 📖 The Story

**What happens when customers lose trust in e-commerce?**

This project begins with a simple but powerful question. Using real transaction data from **Olist** — Brazil's largest e-commerce marketplace with 100,000+ orders — I investigate the systemic failures that erode customer trust in traditional (Web2) online commerce.

**Phase 1** dives deep into the data to expose two critical weaknesses: **logistics bottlenecks** causing widespread delivery delays, and a troubling correlation between late deliveries and **1-star reviews** that drives customers away.

**Phase 2** proposes a radical solution: what if we could automate trust? Using **blockchain technology**, I design a Smart Contract escrow system that holds customer payments and **automatically refunds** them when deliveries fail — no human intervention, no disputes, no waiting.

**Phase 3** validates this vision against reality. By analyzing actual **Ethereum on-chain data**, I examine whether such a solution is economically viable — studying gas costs, transaction volumes, and real user behavior in Web3 marketplaces.

> *The result is a complete, data-driven argument for the evolution of commerce — from centralized trust to decentralized transparency.*
